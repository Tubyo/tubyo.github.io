Mode enfant : un espace vidéo séparé, protégé par un code

Le mode enfant de Tubyo isole les vidéos pour enfants dans son propre espace, avec sa bibliothèque et son historique de reprise. Vous gardez la main grâce au code parental.

Un espace réellement séparé

YouTube Kids et Kidoodle.TV s’ouvrent dans une session dédiée : espace enfant avec sa propre bibliothèque, ses créateurs et sa reprise, sans mélange avec la vôtre.

Protection et durée

Un code parental protège la sortie du mode enfant, vous choisissez une durée de session, et les commandes peuvent être verrouillées pendant la lecture pour éviter les manipulations.

Sans publicité Tubyo

Aucune publicité Tubyo n’est affichée dans le mode enfant, même sans abonnement. Le filtrage des sites reste actif selon les sites compatibles.
