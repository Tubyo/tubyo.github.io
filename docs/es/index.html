La suscripción es opcional

Puede aparecer un anuncio al abrir un sitio y un banner en el inicio. Tubyo no añade pausas publicitarias durante tus vídeos. La suscripción elimina solo estos anuncios de Tubyo; el filtrado de los sitios sigue siendo gratuito.

Respuestas claras.

¿Hay que pagar por el filtrado o el PiP?+

No. Todas las funciones son gratuitas. La suscripción opcional solo elimina los anuncios de Tubyo.

¿Puedo usar subtítulos y elegir la calidad?+

El reproductor del sitio conserva sus controles disponibles. También puedes elegir el reproductor de Apple para las fuentes admitidas.

¿El modo infantil es gratuito?+

Sí, con biblioteca separada, código parental y límite de sesión. No muestra anuncios de Tubyo, incluso sin suscripción.

¿Cuándo podré descargar Tubyo?+

La versión para iPhone y iPad se está preparando para el App Store. Android llegará después. Añadiremos el enlace cuando esté disponible.
